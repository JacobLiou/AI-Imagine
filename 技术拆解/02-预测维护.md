# 预测维护

对应 [AI 成功案例](../AI%20成功案例.md) 的路径二，以及西门子 Senseye 在 BlueScope、Sachsenmilch、Cham 工厂的用法：时序进模型，输出是维修建议，不是自动控制。

BlueScope 自 2022 年起约三年避免约 2,000 小时非计划停机和 53 次完整工艺中断。Sachsenmilch 在计划停机里换掉一台被提前发现的泵，避开低六位数欧元损失。这些数字说明闭环是「提前安排维修」。模型没有去改产线控制。

## 技术决策

预测维护里有三个不同问题，选型前先分开：

| 问题 | 输出 | 什么时候做 |
|------|------|------------|
| 异常检测 | 这台设备现在不像自己 | 有传感器、几乎没有故障标签。先做这个 |
| 诊断 | 更像哪一种故障 | 有维修工单能对上故障模式 |
| 剩余寿命 RUL | 大约还能跑多少周期 | 有跑到失效的历史，或有可信的退化模型 |

Senseye 公开材料覆盖的是异常、阈值、模式，加上解释和维修建议。维护 Copilot 是在这之上用生成式模型读证据和手册。第一版不要承诺剩余寿命天数。寿命模型要的数据，多数棕地工厂没有。

第二个决策是报警接去哪里。能落地的接法是：案例视图、证据、建议，然后由人开维修通知，再进 SAP PM 这类工单系统。Cham 的试点就是远程看案例和证据，而不是让模型写 PLC。

第三个决策是模型复杂度。单一工况、传感器已经挑过的情况下，随机森林或梯度提升往往够用。工况切换会把退化信号淹没时，才需要先按工况归一化，再上序列模型。公开的 C-MAPSS 实验反复出现这个顺序：FD001 单一工况，窗口统计加随机森林是强基线；FD004 多工况，LSTM 才超过随机森林。

## 架构

工业上这套分层有标准名字：ISO 13374 / OSA-CBM。实现时可以收成下面几层。

```text
传感器（振动、电流、温度）
    → 采集与对齐（边缘或历史库）
    → 工况识别与归一化
    → 状态检测：偏离正常吗
    → 健康评估：严重到要开案例吗
    → 预测（可选）：剩余寿命区间，带不确定性
    → 建议：证据、可能原因、建议动作
    → 人确认 → 工单（SAP PM 等）
```

NASA ProgPy 把「模型」和「预测引擎」拆开，适合对照着设计，而不是把一个 notebook 直接部署：

1. **模型**描述状态如何随时间变。可以是机理、数据驱动或混合。数据驱动例子包括 LSTM 状态转移。
2. **引擎**做状态估计、向前预测和不确定性传播。预测常用带噪声的蒙特卡洛滚动。
3. **服务**：ProgPy 自带一个简单的 prognostics 服务端和客户端，用来把估计从算法脚本里拉出来。

现场架构还要有一层厂商案例里反复出现的东西：案例，而不是裸曲线。技术员打开的是「哪台资产、哪段证据、建议做什么」，远程能看。

## 经典技术

- **工况归一化**：用设定值或聚类把工况分开，每个工况内再标准化。不这样做，换挡会被当成故障。
- **健康指标**：从振动里取有效值、峰值、频谱分量；从电流里取与负载相关的残差。先有指标，再谈网络。
- **异常检测**：隔离森林、单类 SVM、自编码器重构误差。适合无标签阶段。
- **剩余寿命标签**：C-MAPSS 社区的常用做法是分段线性封顶（常见封顶在 125 个周期），避免模型去学「还很健康时的精确天数」。按整机划分训练和测试，不能按时间窗随机切，否则泄漏。
- **序列模型**：滑窗后的 LSTM 或 Temporal Convolution。只有在随机森林吃同样窗口统计量仍然不够时才上。
- **不确定性**：MC Dropout 或保形预测，给出区间。维修排程要的是「最晚什么时候必须看」，不是一个点估计。
- **评分**：PHM08 不对称分数，晚报警比早报警罚得更重。这和工厂损失一致。

C-MAPSS 综述里，传感器常先降维。被反复选中的一批涡扇传感器是 7、8、9、12、16、17、20。这是数据集上的经验，不是所有电机的传感器清单。

## 参考范式

1. 选瓶颈设备，棕地接入，不换整线。
2. 先做异常和案例，工单仍由人开。
3. 有跑到失效的数据后，再加 RUL，并且报告区间。
4. 生成式维护助手只解释已有证据和手册，不单独充当报警器。西门子首批试点称反应式维修时间平均少约 25%，那是助手接在预测维护上，不是一个聊天机器人。

## 不要照搬的地方

C-MAPSS 是仿真涡扇，工况和传感器都干净。工厂电机的第一版应是：固定采样、对上维修记录、误报可被班组忍受的异常报警。没有失效历程就不要报告剩余天数。模型输出进工单之前，先让人在案例界面里核对几次真故障。
