# 视觉质检

对应 [AI 成功案例](../AI%20成功案例.md) 的路径一，以及博世类外观检测、富士康类电子外观、德州仪器 AM62A 参考设计。

这篇谈的是：相机看住一个工位，把「这件要不要拦截」变成可重复的判定。TI 的应用笔记 SPRADC9 把这条链路走完了一次：采集、标注、选 YOLOX-Nano、编译到 2 TOPS 加速器、跟踪坐标、看板上统计缺陷类型。实验室 50 件样品、10 圈重复为 100%，30 FPS 时加速器只占 22%、估算功耗 1.43 W。那是转盘模拟传送带，不是产线验收数字。

## 技术决策

先分清缺陷形态，再选模型族。三条路线不要混成一个「上 YOLO」：

| 现场条件 | 选型 | 原因 |
|----------|------|------|
| 缺陷类别清楚，有框或掩码标注，要给出位置和类型 | 监督检测，YOLO 一类单阶段检测器 | 要坐标才能分拣；类别要进质量看板 |
| 缺陷稀少、样子多变，只有大量合格图 | 无监督异常检测，如 PatchCore | 坏样本不够训练分类器；模型学的是「偏离正常」 |
| 光照稳定、缺陷是尺寸、缺口、有无 | 传统视觉：边缘、斑点、模板、测量 | 可解释、延迟低、换型成本小；深度学习解决不了标定问题 |

第二个决策是部署位置。节拍以帧计、图像不出厂时，模型放在工位工控机、Jetson 或 AM62A 这类边缘芯片上，导出 ONNX / OpenVINO / TensorRT。只有需要跨线对比、模型很大时才把图送到服务器。TI 这条参考设计选择边缘，是因为传送带等不了云端往返。

第三个决策是闭环深度。第一版做辅助：框出可疑区域，人确认。误杀成本高于漏检时，不要直接驱动剔除气缸。进入在线拦截之后，每次误判都要回到样本库，否则模型会停在上线那天的分布。

## 架构

```text
光电触发 → 相机（曝光/增益锁定）→ ISP / 去畸变
    → ROI
    → 检测器或异常模型
    → 跟踪（同一件跨帧只计一次）
    → 判定：放行 / 可疑 / 剔除
    → PLC 或分拣机构
    → 原图、框、判定、批次号落库，供复判和再训练
```

跟踪是产线架构里经常被漏掉的一层。检测器按帧输出框，计数和分拣要的是「一件产品」。SPRADC9 单独写了对象跟踪，把坐标交给分拣，并把缺陷类型送进看板。

训练侧和推理侧分开：

- 训练：标注规范、类别表、增强（亮度、小角度、尺度），固定验证集按工位而不是按随机图片切分。
- 导出：把框架模型编成目标芯片能跑的格式，在工位节拍下测延迟，而不是只看离线 mAP。
- 运行：阈值按「漏检成本 / 误杀成本」定，不按验证集最高 F1 直接搬到产线。

## 经典技术

- **单阶段检测**：YOLO 系列。骨干提取特征，颈部做多尺度融合，头同时回归框和类别。小缺陷常改损失函数（如归一化 Wasserstein 距离 NWD）和浅层特征，而不是换一个更大的骨干。
- **无监督异常检测**：PatchCore。用预训练 CNN（常见 Wide ResNet-50）抽出图像块特征，只存合格品的记忆库，用最近邻距离得到异常分数和热图。训练阶段不做反向传播。MVTec AD 是这个方向的公开基准：15 类物体和纹理、只含合格训练图、测试集含 73 种异常。
- **传统视觉**：阈值、连通域、模板匹配、卡尺测量。缺陷定义是几何量时，它仍是基线，用来证明「这个问题是否真的需要网络」。
- **部署**：ONNX 作为交换格式；NVIDIA 用 TensorRT；Intel CPU 用 OpenVINO；TI 用 Edge AI Studio 编译到 C7x/MMA。

## 参考范式

工业质检论文和开源项目反复出现的改法是：拿一个小 YOLO 当基线，只动骨干、颈部或损失，服务「低对比、小目标、要上边缘」。钢表面的 SDM-YOLO、AGE-YOLO，晶圆的 Wafer-YOLO，传送带橡胶的 CMT-YOLO，都是这条范式，不是另一套检测理论。

无监督范式的标准实验是：MVTec 某一类只喂合格图，报告图像级 AUROC 和像素级定位。Intel 的 Visual Quality Inspection 参考流程把这件事收成可配置的特征提取加 OpenVINO 推理。

和成功案例对齐的落地顺序仍是：缺陷定义清楚的一个工位 → 标注规范 → 辅助判定 → 再谈在线拦截。

## 不要照搬的地方

实验室 100% 来自固定样品、固定光照和已知四类缺陷。产线上要重新收图：反光、油污、姿态、相机脏污都会改变分布。有合格图但几乎没有坏样本时，先做 PatchCore 热图辅助复判；等坏样本积累够、类别稳定后，再训练检测器做分拣。
