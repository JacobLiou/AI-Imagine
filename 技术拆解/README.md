# 技术拆解

对照 [AI 成功案例](../AI%20成功案例.md) 第 3 节的六条路径。每一篇只谈一种已经落地的技术：决策、选型、架构、经典方法、参考范式和开源实现。

这些笔记描述的是可复用的工程范式，不是某一家厂商产品的内部设计。厂商案例用来说明「这条技术已经在什么闭环里算出过账」。

| 篇 | 对应路径 | 先做的技术选择 |
|----|----------|----------------|
| [视觉质检](01-视觉质检.md) | 路径一 | 缺陷是否已知、有没有合格样本以外的标注 |
| [预测维护](02-预测维护.md) | 路径二 | 先做健康预警，再决定要不要估剩余寿命 |
| [良率与测试失败预测](03-良率与测试失败预测.md) | 路径三 | 先打通序列号追溯，再上分类模型 |
| [排产与供应链优化](04-排产与供应链优化.md) | 路径四 | 先用约束求解器，预测只提供需求输入 |
| [制造知识助手](05-制造知识助手.md) | 路径五 | 先做带引用的检索，再考虑代理 |
| [工程生成与虚拟试产](06-工程生成与虚拟试产.md) | 路径六 | 生成物必须能编译、能仿真，人确认后才下发 |

读的时候按这个顺序问：输出接去哪个已有动作，失败代价是否可控，数据是不是已经在流。模型选型排在这三个问题之后。
